Calcula $\displaystyle\lim_{n\to\infty}\frac{\sqrt1+\sqrt2+\sqrt3+\cdots+\sqrt n}{n\sqrt n}$.

Pista

Stolz con $b_n=n\sqrt n=n^{3/2}$. Para el incremento $(n+1)^{3/2}-n^{3/2}$, multiplica por el conjugado $(n+1)^{3/2}+n^{3/2}$.

Ver solución
  1. Identificar: $a_n=\sqrt1+\cdots+\sqrt n$ (suma de $n$ términos) y $b_n=n\sqrt n$. Forma $\frac\infty\infty$.
  2. Hipótesis de Stolz (U p.32): $b_n=n^{3/2}$ es estrictamente creciente (producto de dos sucesiones positivas crecientes) y tiende a $+\infty$ ✓.
  3. Incrementos: $a_{n+1}-a_n=\sqrt{n+1}$. Para $b_{n+1}-b_n$, conjugado: $$(n+1)^{3/2}-n^{3/2}=\frac{(n+1)^3-n^3}{(n+1)^{3/2}+n^{3/2}}=\frac{3n^2+3n+1}{(n+1)^{3/2}+n^{3/2}}.$$
  4. Cociente de incrementos: $$\frac{\sqrt{n+1}\,\big((n+1)^{3/2}+n^{3/2}\big)}{3n^2+3n+1}=\frac{(n+1)^2+\sqrt{n+1}\,n^{3/2}}{3n^2+3n+1}.$$
  5. Dividir entre $n^2$: arriba $\big(1+\frac1n\big)^2+\sqrt{1+\frac1n}\to1+1=2$ (porque $\sqrt{n+1}\,n^{3/2}=n^2\sqrt{1+\frac1n}$); abajo $3+\frac3n+\frac1{n^2}\to3$. El cociente tiende a $\frac23$ y, por Stolz, también el límite pedido. Comprobación: para $n=1000$ el cociente vale $\approx0{,}6668$.

Resultado: $\frac23$
