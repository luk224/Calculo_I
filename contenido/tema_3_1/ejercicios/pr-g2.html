Se aproxima $\sqrt{1+x}$ por $1+\frac x2$. (a) Acota el error para todo $x\in[-0{,}1;0{,}1]$. (b) ¿Para qué $x\ge0$ se puede asegurar error menor que $0{,}01$?

Pista

Es $p_1$ en $0$. $f''(x)=-\frac1{4(1+x)^{3/2}}$: su valor absoluto es mayor cuanto menor es $1+c$. En (a), $c$ puede acercarse a $-0{,}1$; en (b), $c>0$.

Ver solución
  1. Polinomio: $f(0)=1$, $f'(x)=\frac1{2\sqrt{1+x}}$, $f'(0)=\frac12$: $p_1(x)=1+\frac x2$ (U p.108).
  2. Resto (U Prop. 3.2, p.111; $f''$ continua en $(-1,\infty)$): $R_1(x)=\frac{f''(c)}{2}x^2=-\frac{x^2}{8(1+c)^{3/2}}$, $c$ entre $0$ y $x$.
  3. (a) Caso peor en el intervalo: para $x\in[-0{,}1;0{,}1]$, $c>-0{,}1$ y $1+c>0{,}9$; además $x^2\le0{,}01$. Usando a la vez el mayor numerador y el menor denominador: $|R_1|<\frac{0{,}01}{8\cdot0{,}9^{3/2}}=\frac{\sqrt{10}}{2160}\approx0{,}0015$. (El error real máximo, en $x=-0{,}1$, es $0{,}0013$.)
  4. (b) Con $x\ge0$: $c>0$, $(1+c)^{3/2}>1$ y $|R_1|<\frac{x^2}8$. Despejar: $\frac{x^2}8<0{,}01\iff x^2<0{,}08\iff x<\sqrt{0{,}08}=\frac{\sqrt2}5\approx0{,}283$.
  5. Comprobación: en $x=0{,}283$ el error real es $0{,}0088<0{,}01$.

Resultado: en $[-0{,}1;0{,}1]$ el error es $<\frac{\sqrt{10}}{2160}\approx0{,}0015$; para $x\ge0$ basta $0\le x<\frac{\sqrt2}{5}\approx0{,}283$
