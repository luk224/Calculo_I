Definición 4.3 · función de dos variables

Una función $f:D\subset\mathbb R^2\to\mathbb R$ asigna a cada $(x,y)\in D$ un único número real $f(x,y)$. $D$ es el dominio y $f(D)=\{f(x,y):(x,y)\in D\}$ es la imagen. Se escribe $z=f(x,y)$: $x,y$ son las variables independientes y $z$ la dependiente. Para $n$ variables, $f:D\subset\mathbb R^n\to\mathbb R$, igual.

Convenio: si no se indica el dominio, es el mayor conjunto donde la expresión tiene sentido.
