Se tiene una tabla de $e^x$ en $0;\ 0{,}1;\ 0{,}2;\dots;\ 1$ y, para un $x$ intermedio, se interpola linealmente entre los dos nodos vecinos. Acota el error para cualquier $x\in[0,1]$.

Pista

Entre dos nodos $a$ y $b=a+h$, el error es $\frac{f''(\xi)}{2}(x-a)(x-b)$. La parábola $(x-a)(x-b)$ alcanza su valor absoluto máximo en el punto medio: $\left(\frac h2\right)^2$.

Ver solución
  1. Forma del error (apartado 4, $n=1$): $|e^x-p_1(x)|=\frac{e^\xi}{2}|x-a|\,|x-b|$, con $\xi\in(a,b)\subset[0,1]$.
  2. Derivada: $e^\xi\le e^1=e$ (la exponencial es creciente).
  3. Producto: $(x-a)(x-b)$ es una parábola que se anula en $a$ y $b$; su vértice está en el punto medio, donde $|x-a|\,|x-b|=\frac h2\cdot\frac h2=\frac{h^2}4$.
  4. Cota: $|e^x-p_1(x)|\le\frac e2\cdot\frac{h^2}4=\frac{e\,h^2}8=\frac{e\cdot0{,}01}{8}\approx0{,}0034$.

Resultado: $|e^x-p_1(x)|\le\frac{e\cdot0{,}01}{8}\approx0{,}0034$
