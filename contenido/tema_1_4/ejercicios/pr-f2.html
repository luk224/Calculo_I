La ecuación $x^3+x-5=0$ tiene una única raíz en $[1,2]$. Aproxímala con 4 iteraciones de bisección, acota el error y di cuántas iteraciones harían falta para un error menor que $10^{-3}$.

Pista

Tabla con $a$, $b$, $c$ y el signo de $f(c)$; quédate con la mitad cuyos extremos tienen signos opuestos.

Ver solución
  1. Hipótesis: $f(x)=x^3+x-5$ es continua, $f(1)=-3<0$, $f(2)=5>0$. Es la única raíz porque $f$ es estrictamente creciente.
  2. $c_1=1{,}5$: $f(1{,}5)=-0{,}125<0$ → $[1{,}5;\,2]$.
  3. $c_2=1{,}75$: $f(1{,}75)\approx2{,}109>0$ → $[1{,}5;\,1{,}75]$.
  4. $c_3=1{,}625$: $f(1{,}625)\approx0{,}916>0$ → $[1{,}5;\,1{,}625]$.
  5. $c_4=1{,}5625$: $f(1{,}5625)\approx0{,}377>0$. Aproximación $c_4=1{,}5625$ con error $<\frac{2-1}{2^4}=\frac1{16}=0{,}0625$ (U p.54). (Raíz $\approx1{,}5160$: error real $\approx0{,}047$.)
  6. Para $10^{-3}$: $\frac1{2^n}<10^{-3}\iff2^n>1000$; $2^9=512$, $2^{10}=1024$: $n=10$.

Resultado: $c_4=1{,}5625$, error menor que $\frac1{16}$; para $10^{-3}$, $n=10$
