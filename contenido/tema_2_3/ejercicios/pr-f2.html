Calcula $\displaystyle\lim_{x\to+\infty}\left(e^x+x\right)^{1/x}$.

Pista

Toma logaritmos: $\dfrac{\ln(e^x+x)}{x}$. Saldrá $\tfrac\infty\infty$ dos veces.

Ver solución
  1. Tipo: base $\to+\infty$, exponente $\frac1x\to0$: $\infty^0$.
  2. Logaritmo: $L=\displaystyle\lim_{x\to+\infty}\frac{\ln(e^x+x)}{x}$, tipo $\tfrac\infty\infty$.
  3. Primera derivada: $\dfrac{(e^x+1)/(e^x+x)}{1}=\dfrac{e^x+1}{e^x+x}$, otra vez $\tfrac\infty\infty$.
  4. Segunda derivada: $\dfrac{e^x}{e^x+1}=\dfrac1{1+e^{-x}}\to1$. Así $L=1$.
  5. Deshacer: el límite pedido es $e^{1}$.

Resultado: $e$
