Sea $f(x)=x^3e^x$. Halla una fórmula para $f^{(n}(0)$ válida para todo $n\ge3$ y calcula $f^{(10}(0)$.

Pista

Multiplica cada sumando de la serie de $e^x$ por $x^3$ y cambia el índice para que la potencia sea $x^n$. ¿Qué vale el coeficiente de $x^n$?

Ver solución
  1. Serie: $x^3e^x=x^3\sum_{m\ge0}\frac{x^m}{m!}=\sum_{m\ge0}\frac{x^{m+3}}{m!}$, válida para todo $x$.
  2. Reindexar con $n=m+3$ (cuando $m=0$, $n=3$): $x^3e^x=\sum_{n\ge3}\frac{x^n}{(n-3)!}$. Los coeficientes de $x^0,x^1,x^2$ son $0$.
  3. Derivadas (U p.118): $f^{(n}(0)=n!\cdot\frac1{(n-3)!}=n(n-1)(n-2)$ para $n\ge3$, porque $n!=n(n-1)(n-2)\,(n-3)!$. Y $f(0)=f'(0)=f''(0)=0$.
  4. Caso $n=10$: $10\cdot9\cdot8=720$.
  5. Control: $n=3$ da $3\cdot2\cdot1=6$; directamente, $f'''(0)=3!\cdot(\text{coef. de }x^3)=6\cdot1=6$.

Resultado: $f^{(n}(0)=n(n-1)(n-2)$ para $n\ge3$; $f^{(10}(0)=720$
